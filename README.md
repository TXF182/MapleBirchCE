# Maplebirch CE · 全局全自动剧情条件解锁

> 对标官方 CE 调试器的全局调试面板：七大面板、恋爱与转化阶段一键完成、场景永久解锁、12 个第三方模组适配、玩家全属性编辑、每日模组更新自动检测。界面全中文、纯 JS 加载。

**当前版本：v2.2.5**（完整版本记录见 CHANGELOG.md）

## 功能

- **七大面板**：角色 / 阶段 / 剧情 / 场景直达 / 全局 / Mod作弊 / 言灵
- **角色**：全属性编辑、原版 170 特质全收录 + 模组特质自动发现、中文特质映射、性别切换（留痕可回退）、恋爱对象与阶段
- **阶段**：原版与模组剧情阶段一键完成 / 回退
- **剧情**：剧情直达与回放、固定触发、节日与怨灵状态、锚定触发
- **场景直达**：地点永久解锁 + 世界入口、悉尼线 / 小岛 / 艾弗里庄园等子入口、26 条数字档位核对
- **全局**：时间 / 天气、世界腐化、犯罪 / 古董 / 成就、原版经济、数值固定、说话态度维持、庄园自动维护、潜伏者自动搬运、食物库存 / 鱼获直写、艾弗里庄园放逐后保留
- **Mod作弊**：12 个第三方模组键级适配（见下表）、类型显示、留痕 + 预览 + 单键回退
- **言灵**：好友诉求一键写入、艾弗里办公室、作弊模式（无副作用开启）、枝叶变装等
- 全部写入留痕可回退；可开启「确认条」先预览前后差异再写入
- 每日 21:15 自动检测所适配模组的新版本，可用官方最新包替换本地旧包

## 安装

1. 游戏内 Alt+M 打开 ModLoader → 添加旁加载 Mod → 选择 `MapleBirchCE.mod.zip` → 刷新页面
2. 右下角出现 CE 悬浮球即生效，点击打开面板；面板主题四档（金色 / 星空蓝 / 赛博朋克 / 青瓷）在全局页顶部切换

> 注意：把 zip 复制进游戏目录**不等于安装**。实机 Mod 由浏览器本地存储加载，请走 ModLoader 导入；核对是否已装载见仓库 `mce-e2e\idb_audit.ps1`。
