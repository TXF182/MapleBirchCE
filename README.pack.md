# Maplebirch CE · 全局全自动剧情条件解锁

> MapleBirch 框架扩展的全局调试面板：右侧常驻悬浮球 → 七页签面板（角色 / 阶段 / 剧情 / 场景直达 / 全局 / Mod作弊 / 言灵）。全中文界面，纯 JS 加载，写入全部留痕可回退。

**分发说明**：本文件是随 `MapleBirchCE.mod.zip` 分发的**简版说明**（安装 + 使用 + 排障）。完整的工程文档、适配器逐项清单、版本线、质量台账在开发仓库的 `README.md` / `CHANGELOG.md`（体积原因未打进 zip）。

## 前置依赖

| 依赖 | 版本要求 | 说明 |
|---|---|---|
| [SugarCube 2 ModLoader](https://github.com/Lyoko-Jeremie/sugarcube-2-ModLoader) | ≥ 2.0.0 | 模组装载器本体 |

| Degrees of Lewdity | ≥ 0.5.12.13 | 游戏本体 |

## 安装

1. 游戏内按 `Alt+M` 打开 ModLoader → 「添加 / 移除 Mod」。
2. 选择 `MapleBirchCE.mod.zip` → 「添加旁加载 Mod」→ 提示 Success。
3. **刷新页面**（不刷新不生效）。若列表中已有同名旧版，先「移除」再导入新版，避免同名单冲突。
4. 刷新后右下角出现**金色圆形 CE 悬浮球**，点击即开面板。

悬浮球可拖动（按住拖到任意位置，位置记忆）。若拖动误触，在「全局」页顶部用「锁定悬浮球拖动」固定；悬浮球是唯一面板入口，不会隐藏。

## 面板七页速查

| 页签 | 能做什么 |
|---|---|
| **角色** | 玩家全属性数值编辑（含相对调整 `+N / -N`）、全部特质获取/移除（原版 170 特质中文映射 + 模组特质自动发现）、NPC 特质 |
| **阶段** | 恋爱阶段一键完成、转化档位推进（列表/状态双通道） |

| **场景直达** | 特殊场景一键传送（阁楼/庄园/神殿/公寓/监狱/农场等）；另一个子页是「地点」阶段任务（市政改造/农场/公寓/机构阶段变量直改） |
| **全局** | 世界腐化/堕落度、时间与时段调节、自动维护调度（艾弗里/农场/神殿/伊甸/补给/打扫）、回退中心入口 |
| **Mod作弊** | 第三方模组扩展内容的作弊控制（任务/阶段/能力/剧情/数值），另有「玩家自己」属性入口 |

## 写入安全

- **全部留痕可回退**：每次写入记入 `V.mbCE_wrote`（键前缀 `cheat:` / `place:` / `maint:` / `world:` 等），「全局」页的**回退中心**可按项、按组、全量还原到写入前状态。
- **父宿主缺失即拒绝**：不写 `undefined`、不臆造中间容器（`town_projects` 例外，原版语义本身按字段直写）。
- **类型纪律**：模组源码用 `is 1`（严格 `===`）判定的键走数字通道写 `1/0`，禁 boolean，否则写入静默失效。
- **不碰原版变量**：只暴露模组自建键与原版面板语义一致的档位变量，范围外请走对应页签。

## 常见问题

| 现象 | 处理 |
|---|---|
| 刷新后没有悬浮球 | 确认 ModLoader 列表里 CE 是「启用」且已刷新页面；F12 控制台看是否有 `MapleBirchCE` 加载报错 |
| 面板打开但显示「未检测到 Maplebirch 框架」 | 框架未装或版本过低（< 5.4.2），或加载顺序在 CE 之后 |
| 某模组显示「未声明」 | 该模组未按注册协议声明可操控项，只识别展示；升级 CE 或等适配 |
| Mod作弊页提示「模组要求先开启原版作弊页」 | 该适配项的联动补足依赖原版作弊页状态，先开原版再操作 |
| 数值写了但界面没变 | 部分模组在下一次事件/进页面时才重算；数值锁定类需切换页面 |
| 改崩了 / 想还原 | 「全局」页 → 回退中心，按项或全量回退 |

## 更新

内置**每日模组更新检测**（默认 21:15），检测到适配的第三方模组有新版本时给出提示；也可以手动在面板内触发。CE 自身更新：下载新 `MapleBirchCE.mod.zip`，按上面的安装步骤替换（先移除旧版）。
